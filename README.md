### ♡ About

**prsena.exe** is my personal developer portfolio, inspired by cozy midnight studies, retro operating systems, and the little things that makes me happy.

It's a home for my projects, interests, and journey through software engineering, cloud computing, and cybersecurity.

### ✧ Features

- Retro-inspired window interfaces
- Cozy, handcrafted pixel-art illustrations
- Interactive project showcase
- Personal digital diary
- Persistent music player
- Responsive and accessible design
